[短链设计](SHORT_LANE_DESIGN.md)与 [ADR-0024](../../../decisions/0024-UNIFIED-ENTRY-AND-SHORT-TASK-ROUTING.md)集中定义各分支接点。角色规则须版本绑定、评审并记录实际使用；不将“段落修改”等例子硬编码成永远无研究影响，也不为 Guide/短程任务强造研究 Protocol。本轮再定义六项有具体消费者和验收的增量 Task；原三项桥接继续独立，不以文档接受或旧版本成功代替新路径实现。

人员分工限制按已接受的 [ADR-0023](../../../decisions/0023-DEVELOPMENT-WITHOUT-PERSON-ASSIGNMENTS.md) 撤销。审查按变更风险和证据组织；M0-008 的既有 DONE 事实保持，本 PR 不修改治理配置或远端 ruleset。

## 实施批次与可并行范围

批次是排程建议，不是研究 DAG，也不覆盖 TASKS 的精确依赖。PR 可原子集成已定义的耦合切片，但每项保留独立提交、验收证据和完成判断。

1. **基础接口。** 推进 M4-006、M8-006、M9-007 及多意图分流 M1-014；M0-008 的既有 DONE 事实保持。M6-011 能力/用量增强与 M6-013 契约迁移可以在独立范围推进，不成为所有开发的共同前置；原 M1-010/M2-009/M11-008 先按候选代码和完整 Task 验收查缺补齐，不能从 PR140 的局部成功直接置 DONE。M11-008 的 no-Skill/direct Tool Core 全桥可独立收口，Skill 缺资格的阻断必须证明；不等待未来 loader，也不宣称实际 Skill 已验收。合格 Skill 正路径由 M2-012/M11-010 完整闭合。基础项读写范围可分开；共享契约改动串行协调。
2. **实际选择与执行。** 依拓扑推进自然需求/两种初始化、角色指令审查、不同 child 路径、真实 Skill loader、Guide 与写入/执行 Tool。必载角色规则承担最低职责，可选 Skill 补具体方法；无 Skill 路径独立可用。真实 Skill 供应不足时保留支线阻断并继续合法 no-Skill 工作。
3. **有效交付与持续材料消费。** 补 Task 内容检查、大输入与证据回查、partial/定向修复、短 MainState 和研究对象接合。格式/内容错误可在原授权内按原因定向修复；权限不足、input drift 或已有外部副作用不能当普通格式错误重跑。费用/token unknown 是记账缺口，不单凭它阻断、否定有效产物或自动重试。
4. **安装入口与研究整链 Gate。** 用已安装包、项目配置和受控工程材料接通 M1-013/M11-010；从0与人工材料两个入口，任务应实际改变合法 Mode/Tool/Skill/Profile/子任务选择。先验通运行体系，后续真实复杂研究和净价值评估分别另立执行范围。
5. **前置层与长短路汇合。** 按精确依赖完成后置影响 M3-013、独立短程 M2-014，再以 M1-015 汇合已安装研究入口、Guide 和短程。M11-011 验证统一入口实际投递/隔离和状态消费；它追加分支覆盖，不倒置为原 M11-010 的前置，也不重构既有研究主线。

每次激活后继项先核 TASKS deps。应用层增加合法 producer/consumer 可复用既有契约；改变核心对象身份、选择/歧义语义、人类决定边界或 Runtime 权威时，先完成对应版本/ADR/R2，再实施，不以任务表自动接受方案。

## 验证和可读交付

### 当前推进与人类决定

原 READY 基础项可按已接受定义推进，本轮修订定义在 PR 审阅后采用。M0-008 已 DONE；按完整验收核对 PR140 原三项桥接的代码、消费接点与证据，并补齐可安装包内的受信 caller/factory。其他 READY 基础项可在互斥范围内并行，具体状态仍由 TASKS 维护。

| 决定面 | 当前采用的既有规则 | 需要人类决定的时点 |
|---|---|---|
| 角色规则与方法 Skill | 准备可版本绑定的职责规则、测试和可读审核材料；baseline 与方法 Skill 资格分别处理 | 正式接受规则或真实 Skill 供给时；候选不自动准入 |
| 多个合格供给与方法提交 | 沿用显式选择、歧义阻断和现行 Human Gate，不新增自动排名或授权政策 | 提议改变选择/歧义语义或人类决定边界时，给出具体方案和 ADR |
| Tool 与数据范围 | 先用已有授权内的受控工程材料、隔离目录和明确操作 | 需要新的外写、进程、网络或数据出口范围时，提交具体动作与范围 |
| 代码合并、真实项目与发布 | 开发和验收持续推进；准备当前 diff、证据与剩余限制 | 每项具体合并/发布或真实项目接入另按人类指令，不提前要求空白批准 |

既有具体 live grant 的累计上限和付费窗口按原授权解释，不成为通用产品或文档/代码/离线验证的额度要求。本轮不改变该 grant、不发付费请求；后续真实验证按实际适用授权和配置开展。无 Skill 正路径独立收口，实际合格 Skill 正路径不足时明确保留 M2-012/M11-010 的相关缺口。

每个 Task 先跑与新增行为相关的确定性正反检查，再按实际适用 grant、source/config/credential refs 做需要的实际 API 验证。测试配置作为配置记录，不生成通用上限。一次工作流可以包含多个 API 会话，子 Agent 数量由 main 在授权内决定。全部实际失败、unknown 和未开始事实保留，程序关联新 Task/Attempt 的实际消耗而不设置通用经济配额；本轮文档提交不发付费请求。

工程 Gate 的最小可读交付应包含：输入目标与材料；本次启用模块/角色/Mode/Skill/Tool 及理由；实际产物与内容片段；逐桥 producer→consumer 和检查结果；实际费用/失败/partial；MainState 与人类决定；未读/未验证项。JSON/Trace/Receipt 是可复核附件，不能替代读者能理解的结果报告。

研究入口接受同时检查两类初始化、至少两个需求引起的不同执行选择、无子/有子及不同 specialist 消费、真实 Tool 副作用/取消、技术容量及程序用量记录、内容失败的定向处理、大结果回查、Guide 事实保真，以及安装包不依赖私有 harness。Skill 路径须另有实际合格供给；缺供给时明确工程 loader 通过与真实 Skill 尚未验证，不能将整项 M11-010 记 DONE。追加分支按短链设计检查实际角色规则版本、路由理由、授权/context、diff/check、影响/采纳和通知；无影响且 refs 有效的局部编辑不改变 MainState 或 main 上下文。上述是受控工程接通测试，科学主张与真实项目准入另行决定。

M5 四臂/盲评/Pilot 与 net benefit，Mode/Skill 准入，后续复杂研究，M12/Topic 5 自动连续性，M13 策略和每次 release 均保留独立 Gate。人工新 Task 显式消费获准 MainState 不构成自动恢复；需要自动迁移/恢复的部分停止在 Topic 5 architecture review/task-definition 前。


## 三条增量线与具体汇合点

| 建设线 | 接入顺序与可演示结果 | 汇合条件 |
|---|---|---|
| 研究记忆与工作集 | M3-010/012 与 M2-010 先提供读取、当前视图和角色装配；M3-014 可按范围找到来源/旧失败/关键反证；M3-015 再做有来源的增量纠正 | 读取不等待维护，当前完成/失败不等待摘要；新 ref 仍经获准读取和冻结，M12 不等待全部记忆功能 |
| 复合意图与有限方向 | M1-014/011 保留原请求、共同限制及依赖；M2-011 成熟后以 M2-015 组织活跃任务内单层方向；M1-015 分别返回结果 | A/B 可是同一研究的方向而非两个项目；父任务比较当前基线再分别采纳，不把兄弟聊天注入 main，不新增直接 child 控制权 |

第一增量：多意图细化、实际角色/工具接合；并行做事件读取/只读前端与工作集接口。第二增量：有效交付、当前状态、证据读取和研究对象按原依赖推进，再接工作集与有限方向。第三增量：统一隔离入口、增量维护和父任务结果接收。批次只表投入方向，不新增 hard dependency。M12/Topic 5 自动上下文替换、跨进程迁移恢复及 M13 策略按原激活条件；新任务不倒挂为 PR140 原三项或 M11-011 的额外全局前置。

| M6-013 | 已有 Task/ref/Session/View/closeout 版本是迁移的源契约；直接从这些 DONE 接口开始，不能靠隐藏 Prompt 或极大额度伪装取消限制 |
| M11-010 增加 M6-013 | 完整产品 Gate 需要真实的新版本模型请求/无额度运行/双版本证据；这约束最终验收，不将迁移挂到原桥接的启动条件 |
| M1-016 → M1-017 | 前端需要可重读事件和事实快照，不能由解释模型补造状态；不需要 M1-015 全路由或维护 Agent |
| M3-014 | 范围读取提供源版本，MainState 提供当前视图，角色装配提供实际注入消费者；缺任一项无法验证选取、陈旧或实际使用 |
| M3-015 | 索引/读取接口、合法研究对象来源及已检查交付提供纠正/维护输入；不得以后台整理补造接受 |
| M2-015 | 实际 child 选择、父任务当前视图和结果检查是方向起点与选择性采纳的消费者；不要求通用持久研究树或恢复系统 |

每项精确 hard dependencies 只在 TASKS；新依赖必须指出缺哪个产物及何以不可安全正确消费，同主题或上一批次不是理由。

## 共用验收素材

- **复合请求**：查询、局部编辑、A/B 研究比较附共同限制。保留对应/依赖，查询可先交付，研究失败不抹去正确结果；冲突和依赖失败分别处理。
- **读取与纠正**：低频有效失败条件、已更正旧判断、不同任务偏好和无关材料。检查有效决定/反证、权限、源版本、陈旧缓存；维护关闭仍可读取，当前完成不被历史 pending 覆盖。
- **方向与展示**：两方向一成功一失败，父任务期间发生相关修改。比较新基线、保留诊断/分歧；解释关闭、刷新、断连不伪造完成或重复副作用。
- **用量与模型输入**：无经济额度仍可运行；请求中默认没有预算管理字段/指令；Provider 没报告用量但有效成果被独立检查，记账标 unknown；响应/证据缺失与记账缺失区分；旧版停止行为、权限拒绝及 hash drift 仍按准确版本验证。

各场景进入其直接任务验收，不建立总评测平台或更改 M5 冻结协议。记录研究产物、人工纠正、首个有效动作等待、选择/回查、重复工作、旧信息沿用、方向和维护/解释实际消耗，不预写收益数字。

具体定义差异与读写边界见 [本轮规划整改记录](PLANNING_USAGE_REPLAN.md)，运行语义见 [ADR-0025](../../../decisions/0025-USAGE-RECORDING-AND-MODEL-WORKING-INPUT.md)。
