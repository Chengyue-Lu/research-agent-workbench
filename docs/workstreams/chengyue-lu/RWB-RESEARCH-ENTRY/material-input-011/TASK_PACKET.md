## 输入、产物与消费

- 输入为显式 Task 文件引用、现有 source-admission sidecar、原始文件与本次选中派生项的精确 pins；新读取权来自 Task 的允许集，来源记录不制造权限。
- 普通 UTF-8 文件保持当前读取行为；来源材料使用同次捕获字节核 hash、原件关联与选中派生来源。未获准文件不因出现在 sidecar 内被读取。
- 产物为实际角色输入的文本快照及材料来源记录；intake、编译器、冻结执行和派发前复验使用同一组获准 refs，之后正式 Handoff 与主消费者按既有契约接收实际结果。
- 不读取 sources/inbox、凭据、隐藏推理、旧 API 日志或未授权目录；多格式解析/大输入检索归 M3-010，当前限制和 unknown 如实交付。

## 验收与停止

先验证普通输入与明确原件/sidecar/派生链，再验证缺 pin、缺来源记录、错 hash、错关联和未授权派生拒绝；未选择的派生项不得额外读取。真实离线 intake→包内受信工厂→Bundle/View→Host→正式 Handoff→主消费及独立安装包形成消费证据，不能仅以新 helper 单测代替整链。

Root 的工程归档可使用任务指定的独立证据目录，以保留完整安装 case 工件。若归档路径影响宿主文件操作，保存原失败，再以同一包、产品、测试与相对输入布局改用更短归档根复验；仅调整归档位置，不改变校验、权限、预算或 Provider 行为。没有原始异常详情时，恢复结果不能单独证明具体宿主根因。
